Ventilation Validation Tool from BIM Models

# Summary:  
This project involves creating a tool to extract ventilation components, quantities and airflow properties from BIM-models. The tool streamlines compliance validation for ventilation systems by analyzing IFC-files and generating structured data for engineers.

# Focus Area and BIM Use
Focus Area and BIM Use Our use case involves creating a tool capable of extracting data such as ventilation components, quantities, and airflow properties from a BIM model. The tool compiles the data into a structured format, which can then be directly used for validating ventilation system design against building regulations and project requirements. This includes comparing the quantities and capacities of components such as ducts, air handling units (AHUs), and pipes with the specifications outlined in the design reports. In short, the goal of the tool is described as the following: Streamline the process of validating ventilation systems in a BIM model by compiling all necessary data for engineers to perform regulatory and design compliance checks. The tool was created entirely within Blender, utilizing the program's scripting prompt and the BlenderBIM add-on. The script was developed exclusively in the Python programming language.

# 3: Define a Function to Extract Components:
```python
def extract_components(file):
    ventilation = file.by_type("IfcDistributionElement")  
    heating = file.by_type("IfcFlowTerminal")  
    cooling = file.by_type("IfcEnergyConversionDevice") 
    pipes = file.by_type("IfcFlowSegment")  
    electrical = file.by_type("IfcCableSegment")  
    fire_systems = file.by_type("IfcFireSuppressionTerminal")  
    ahu_units = file.by_type("IfcBuildingElementProxy") 
    technical_installations = file.by_type("IfcFlowController")
    
    return ventilation, heating, cooling, pipes, electrical, fire_systems, ahu_units, technical_installations
```
This function extracts various components from the IFC model, grouping them by type (e.g., ducts, pipes, AHUs).

# 4: Extract Components from MEP and ARC Files:

ventilation, heating, cooling, pipes, electrical, fire_systems, ahu_units, technical_installations = extract_components(mep_file)

# 7: Define a Function for Ventilation Calculations:
```python
def ventilation_need(n, q_p, A_R, q_b):
    q_tot = n * q_p + A_R * q_b
    return q_tot
```
This function calculates the total ventilation needs for a room based on:
- Number of occupants (`n`).
- Ventilation rate per person (`q_p`).
- Room area (`A_R`).
- Ventilation rate per unit area (q_b`).
