
# 03 A Markdown File for the Use Case Tool:

# About the Tool

# Problem/Claim the Tool is Solving:
The tool addresses the problem of ensuring that ventilation systems including AHUs, ducts, pipes and other technical installations, comply with regulatory standards and design specifications. The claim that needs verification is whether the amount of ventilation components and their specifications match the requirements set forth in the MEP-design report, ensuring a properly functioning ventilation system.

# Where the Problem was Found:
The problem was identified during the process of validating the MEP report for a building's ventilation system. The need arose to check if the installed components align with the design specifications and regulatory standards, particularly in terms of quantities, dimensions, and airflow capacities.

# Description of the Tool:
The OpenBIM ifcOpenShell Tool is designed to:

1. Extract Ventilation Data: The tool extracts information from the IFC model regarding ventilation components such as AHUs, ducts, pipes, valves and dampers.
   
2. Validate Compliance: The tool compares the extracted data against the MEP-report to verify that quantities, dimensions and airflow capacities align with the required specifications and building regulations.
   
3. Calculate Ventilation Requirements: The tool calculates the required airflow for each room based on factors such as room size and occupancy.

4. Generate a Validation Report: After performing the above checks and calculations, the tool generates a report that highlights whether the ventilation system meets the design and regulatory requirements.


# Instructions to Run the Tool:

1. **Step 1: Extract Ventilation Data**
   - Input: IFC file containing the building model data.
   - Action: The tool will extract ventilation data, including AHUs, ducts, pipes and flow controllers, from the IFC file.
   - Output: A structured list of ventilation components with relevant properties (e.g. flow rates, dimensions).

2. # Step 2: Validate Against MEP Report:
   - Input: MEP report containing design specifications for ventilation components.
   - Action: The tool will compare the extracted data from the IFC model with the MEP report to check for discrepancies.
   - Output: A list of validated components and any discrepancies.

3. # Step 3: Calculate Ventilation Requirements:
   - Input: Room sizes and occupancy data from the IFC model.
   - Action: The tool will calculate the required airflow for each room based on the size and number of occupants.
   - Output: Calculated airflow requirements for each room.

4. # Step 4: Generate Validation Report:
   - Input: Data from previous steps.
   - Action: The tool will generate a report detailing whether the ventilation system meets design and regulatory requirements.
   - Output: A comprehensive validation report.


# Advanced Building Design:

# Which Stage of Advanced Building Design (A, B, C, or D) Would the Tool Be Useful?
The tool would be most useful in Stage C (Design Validation) and Stage D (Installation and Operation). During these stages, it is crucial to ensure that the design matches regulatory requirements before installation and that the actual installation meets the specifications.

# Which Subjects Might Use the Tool?
- Mechanical Engineers: For validating HVAC systems and ensuring compliance with design and regulatory standards.
- BIM Managers: For overseeing the implementation and validation of BIM models in construction projects.
- Facility Managers: For ensuring the correct functioning of the ventilation system post-installation.

# What Information is Required in the Model for the Tool to Work?
The model must contain the following information for the tool to function effectively:
- AHUs (IfcBuildingElementProxy)
- Ducts and Pipes (IfcFlowSegment)
- Valves, Dampers, and Other Technical Installations** (IfcFlowController)
- Geometric and Performance Properties** of the components (e.g., dimensions, flow rates, and capacities)
- Room Dimensions and Occupancy Data** to calculate airflow requirements.
