# Script Description: AHU Analysis with ifcopenshell

# Description of Your Script:
This script utilizes the `ifcopenshell` library to open and analyze an IFC-file containing building informations. especially, it applies a custom rule (`AHURule`) from an external module (`rules`) to evaluate AHUs (Air Handling Units) within the model. The script then outputs the results of the rule check, indicating the number or status of the AHUs detected.

# Analysts:
This script is designed to assist in analyzing building models by automaticing the identification and validation of AHUs according to the predefined criteria in `AHURule`. It ensures efficiency and consistency in checking building designs for compliance or completeness regarding AHUs.
